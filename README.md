# Personal Portfolio & Project Showcase

A curated collection of practical web applications built to solve everyday problems through clean interfaces, useful features, and responsive design.

## Projects

| Project | Description |
| --- | --- |
| [AI Study Assistant](AI%20Study%20Assistantng%20Assistant/) | A study-focused assistant for organizing learning workflows and academic tasks. |
| [AgroSmart Smart Farming Assistant](AgroSmart%20%20Smart%20Farming%20Assistant/) | A smart farming concept designed to support modern agricultural decision-making. |
| [Personal Portfolio + Project Showcase](Personal%20Portfolio%20%2B%20Project%20Showcase/) | A personal portfolio website for presenting projects, skills, and professional work. |
| [Small Business Management System](Small%20Business%20Management%20System/) | A simple management interface for handling common small-business operations. |
| [Student Expense Tracker](student-expense-tracker/) | A practical tool for recording, monitoring, and understanding student expenses. |

## Technology

The projects in this collection are built primarily with:

- HTML5
- CSS3
- Vanilla JavaScript
- Node.js, where backend functionality is required

## Getting Started

1. Clone the repository:

	```bash
	git clone https://github.com/Lalit-regar/Personal-Portfolio-Project-Showcase.git
	cd Personal-Portfolio-Project-Showcase
	```

2. Open any project folder.

3. For a static project, open its `index.html` in a browser. For the AI Study Assistant, install its dependencies and start the server when required:

	```bash
	npm install
	node server.js
	```
